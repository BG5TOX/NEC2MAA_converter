## 1. 快速开始

### 1.1 最小可用文件

```nec
CM Half-wave dipole at 14.1 MHz
CE
GW 1 21 0 0 5.0 0 0 15.0 0.001     ' tag=1；21 段；沿 +z 从 5 m 到 15 m；半径 1 mm
GE 0                                ' 几何段结束（0 = 无地面镜像）
EX 0 1 11 0 1.0 0                   ' 电压源：加在 tag=1 的第 11 段
FR 0 1 0 0 14.1                     ' 单频 14.1 MHz
EN                                  ' 文件结束
```

### 1.2 30 秒规则清单（最容易踩的 10 条）

1. 文件＝**几何段** → `GE` → **控制段** → `EN`；`NX` 表示"另一个数据集"。
2. **几何卡与变换卡按文件顺序生效**：`GS`/`GM`/`GX`/`GR` 只作用于**此前已读入**的结构。
3. 卡名 2 字母、大小写不敏感；字段用**空格和/或逗号**分隔；注释 `'`、`!`、弯引号 `‘’“”` 必须**先截断再切字段**。
4. NEC 内部单位一律**米**；`GS` 缩放全部尺寸**含半径**；到 `GE` 时坐标必须已是米。
5. `GW` 的 `NS=0` ⇒ **不生成任何线段**（仅用于取消对称标志）；`RAD=0` ⇒ **下一张卡是 `GC`**（锥度）。
6. `GX` 的 `IXYZ` 是**一个三位整数**（百/十/个 ⇒ X/Y/Z 面），按 **Z→Y→X** 顺序复制、tag 增量每次翻倍 —— 绝不可当三个字段读。
7. `GM`：顺序 Rx→Ry→Rz→平移；`NRPT=0` 是**移动**、`>0` 是**复制**（每份由前一份再变换）；`ITS` 是 tag、**十进制**、范围到结构末尾。
8. `SY`（4NEC2 生态扩展，非 NEC 官方卡）：**按文件顺序求值**、声明先于使用、同名重定义＝顺序赋值；`^` 是**幂**（不是异或）。
9. `GH` 在 NEC-2 与 NEC-4 中**同名不同义**，两版都是 9 个数值字段 ⇒ 必须由选项/用户判定（默认 NEC-2）。
10. 求值失败**不要静默当 0**（会几何塌缩）；生成卡与复制卡要有数量护栏。

### 1.3 解析流程（语言无关）

```
for line in file:
    line = strip_comment(line)              # ' ! ‘ ’ “ ” 之后全部丢弃
    if blank(line): continue
    card, fields = split_card(line)          # 卡名＝行首 2 字母；字段按"该卡的字段个数"还原
    switch card:
      SY              -> parse declarations; evaluate IMMEDIATELY in order into symbol table
      GW GC CW GA GH  -> create wires (scale coordinates by current GS factor)
      GM GX GR        -> transform/copy existing wires (order & tag rules!)
      GS              -> scale ALL accumulated wires (incl. radius); update current factor
      GE              -> geometry section ends (control cards follow)
      NX              -> stop reading (only the first dataset is kept)
      CM CE           -> comments
      default         -> control cards (FR EX LD TL NT GN GD IS UM VC JN RP NE NH PT PQ XQ EK KH PS MX CP …)
    on any evaluation failure: record a warning (never silently use 0)
```

## 2. 文件结构

### 2.1 两段式结构

```
[CM … CE]                        ← 可选标题/注释块（CM 可多条；CE 结束）
┌ 几何段（Structure Geometry）──────────────────────────────┐
│ GW GC CW GA GH              生成导线                       │
│ GM GX GR GS                 变换/复制/缩放                  │
│ SP SM SC                    面片（面，不是线）              │
│ GF WG                       数值格林函数文件读写             │
└──────────────────────────────────────────────────────────┘
GE                                ← 几何段结束；此后单位必须是米
┌ 控制段（Program Control）─────────────────────────────────┐
│ FR EX LD TL NT              频率/激励/负载/传输线/网络      │
│ GN GD IS UM VC JN           地面与介质                      │
│ RP NE NH LE LH PT PQ PS CP XQ MX  输出请求与选项            │
└──────────────────────────────────────────────────────────┘
EN                                ← 文件结束
```

- 控制卡**无固定顺序**，但按读入顺序生效；未设置项在求解时取默认值（默认频率 299.8 MHz ＝ 波长 1 m）。
- `GE` 之前不得出现控制卡；`GE` 之后不得出现几何卡。

### 2.2 行语法

| 项 | 规则 |
|---|---|
| 卡名 | 行首两个字母（所有 NEC 卡都是两字母）；大小写不敏感 |
| 字段分隔 | **空格、逗号、制表符**皆可；连续分隔符与首尾空白允许 |
| 字段顺序 | 按"卡定义中的字段序号"，**不要按列位置**（列位置表是历史固定格式约定） |
| 例外 | 少数卡的值是"**一个整数的多位数字**"：`GX` 的 `IXYZ`、`RP` 的 `XNDA` —— 必须整体读取 |
| 注释 | `'`（NEC-2 生态通用）、`!`（NEC-4 明文规定"数据之后以感叹号结束即可写文档"）、文字处理器产生的弯引号 `‘ ’ “ ”` |
| 空行/缩进 | 一律忽略 |
| 行首 `*` | **不是** NEC 规范（真实文件中未见使用）；可选容忍 |
| 大小写 | 卡名、符号名、表达式均大小写不敏感 |
| 小数分隔符 | 恒为 `.`（**不是逗号**；逗号只作字段分隔） |

⚠ **字段内空格**：4NEC2 允许表达式里带空格，例如 `GW 1 10 0 0 A + H 0 W A + H - h2 0.5*1e-3`。
按空白机械切分会**整体错位**（坐标错、半径落到别的字段）⇒ 解析器必须按"该卡固定字段数 + 表达式语法"还原字段（见 §7、§8）。

### 2.3 单位制与 `GS`

- NEC 内部一律**米**；`GS 0 0 FSCALE` 把结构尺寸（**含导线半径**）乘以 `FSCALE`。
- `GS` **按读入顺序生效**：缩放此前已读入的几何；其后读入的几何按新单位解释。
  标准写法是把 `GS` 放在所有几何卡之后（`GW …` → `GS 0 0 0.3048` → `GE`）。
- 常见 `FSCALE`：`0.3048`（英尺）、`0.0254`（英寸）、`1`（米，冗余）。

### 2.4 wire / segment / tag

| 概念 | 含义 |
|---|---|
| **wire** | 一张 `GW`/`GA`/`GH`/`CW` 卡生成的一根导线（两端点 + 半径 + 段数） |
| **segment** | 导线被分成 `NS` 个小段（矩量法的未知量）；**激励/负载/传输线都挂在段上** |
| **tag** | 该导线（其全部段）的整数标签；`tag=0`＝无标签（不能被按 tag 引用，变换时也不递增） |

- 段的引用方式：**（tag, 该 tag 组内第 m 段）**，或**绝对段号**（按文件中段的排列顺序，从 1 开始）。
- 导线"相连"的判据是**端点坐标完全相同**；中途相交时，交点必须正好落在两边的段边界上。
- 导线方向（end-1 → end-2）定义正电流参考方向，影响激励极性。

### 2.5 多数据集（`NX`）

一个文件可含多个数据集（各自的几何段 + 控制段），以 `NX` 分隔。`NX` 之后的内容属于**另一个数据集**。
只支持单结构的工具应"只取第一个数据集"或明确告警，**不要**把多个结构合并。

## 3. 几何卡

### 3.1 `GW` — 直线导线

```
GW  ITG  NS  X1  Y1  Z1  X2  Y2  Z2  RAD
     I1   I2  F1  F2  F3  F4  F5  F6  F7
```

| 字段 | 类型 | 含义 |
|---|---|---|
| `ITG` | int | 标签；0＝无标签 |
| `NS` | int | 段数；**`NS=0` ⇒ 不生成任何线段** |
| `X1..Z2` | float | 两端点坐标 |
| `RAD` | float | 导线半径；**`RAD=0` ⇒ 下一张卡必须是 `GC`** |

**两条特殊语义（最易读错）**

1. **`NS=0` 不生成线段**：手册原文 *"A GW command with NS equal to zero will set the program to a no-symmetry condition **without modifying the structure**"*；
   此时 `RAD` 必须非零（否则程序会去读下一张 `GC`）。实际文件用它"关掉"可选导线（`GW 62 0 0 0 8 0 1.1 8 5.e-3`）。
2. **`RAD=0` ⇒ `GC` 续行卡**：本卡只给几何与段数，半径由下一张 `GC` 给出（§3.2）。

其他实际形态：`NS` 为表达式且求值成小数（`dal20/sl` = 16.19，实现按四舍五入/截断，不同实现可能不同）；
坐标写成符号表达式（`gap/2 + x1`）。

### 3.2 `GC` — 锥度导线（变半径 / 变段长）

`GW … RAD=0` 之后的续行卡。自由格式：

```
GC  IX  0  RDEL  RAD1  RAD2  [DEL1  DEL2]
    I1  I2  F1    F2    F3    F4    F5
```

| 字段 | 含义 |
|---|---|
| `IX=0` | `RDEL`＝相邻段长之比（`RDEL=1` ⇒ 等长）；`DEL1/DEL2` 不使用 |
| `IX=1` | `DEL1`＝**首段长度**（`RDEL` 位置填 0） |
| `IX=2` | `DEL1`/`DEL2`＝**首段 / 末段长度**（此时 `NS` 被忽略，由公式反算段数） |
| `RAD1`/`RAD2` | 首段 / 末段半径 |

公式（`L`＝导线全长，`NS`＝段数）：

```
首段长度   Δ₁ = L·(1−RDEL) / (1−RDEL^NS)          （RDEL = 1 时 Δ₁ = L/NS）
第 i 段长度 Δᵢ = Δ₁ · RDEL^(i−1)
半径比     RRAD = (RAD2/RAD1)^(1/(NS−1))          ⇒ 第 i 段半径 = RAD1 · RRAD^(i−1)
IX=2 反算  RΔ = (L−Δ₁)/(L−Δ₂) ； N = 1 + ln(Δ₂/Δ₁)/ln(RΔ)（四舍五入）
           再以 N 与 Δ₁ 重解 RDEL（手册：末段长度会与请求值略有出入）
```

**示例**：`GW 31 41 … 0` + `GC 0 0 1 .00045 .0006` ⇒ 41 段等长；`RRAD = (0.6/0.45)^(1/40) = 1.00722`，
半径自 0.45 mm 每段 ×1.00722 递增到 0.60 mm。

⚠ 工程含义：锥度导线的强度由**最细处**控制。只支持等半径的工具取小端更保守；要忠实则按段拆分。

### 3.3 `CW` — 悬链线（**NEC-4 新增**）

```
CW  ITG  NS  X1  Y1  Z1  X2  Y2  Z2  RAD  ICAT  RHM  ZM
```

| 字段 | 含义 |
|---|---|
| `ITG/NS/X1..Z2/RAD` | 同 `GW` |
| `ICAT=1` | `RHM`＝自第一端起算的**水平距离**；`ZM`＝该处**高度** |
| `ICAT=2` | `RHM`＝水平距离；`ZM`＝该处**相对两端连线的垂度** |
| `ICAT=3` | `RHM`＝**悬链线总长**（小于两端直线距离 ⇒ 手册规定退化为直线） |

- 曲线位于**两端点决定的竖直平面**内（重力沿 −z）；`RHM` 沿该平面内的水平方向量取。
- 段在悬链线上按**等弧长**均分后**内接**（曲率大处段长略短）；总段长略小于曲线长度。
- ⚠ `ICAT=1/2` 的约束点不宜离两端太近（反解病态）。
- 数值实现要点见 §8.3。

**示例**（39.28 m 跨、两端高 20 m、跨中垂度 1 m）：

```nec
CW 1 39 -19.64 0.0 20  19.64 0.0 20  0.001  2  19.64  1
GE 0 1
```
实际弧长 ≈ 39.35 m，跨中最低点 z ≈ 19.00 m（悬链线参数 a ≈ 187 m）。

### 3.4 `GA` — 圆弧

```
GA  ITG  NS  RADA  ANG1  ANG2  RAD
```

- 圆心在**原点**、轴为 **y 轴**、弧在 **x-z 平面**；
- 角度自 **+x 轴**起算，**绕 +y 轴按左手方向为正** ⇒ 点(角 a) = `(RADA·cos a, 0, RADA·sin a)`；
- 弧分成 `NS` 条**直线段**内接；`ANG2 < ANG1`、`|ANG2−ANG1| > 360` 均合法。

```nec
GA 1 38 2.5 -90 90 0.0075   ' 半径 2.5 m 的半圆：(0,0,−2.5) → (2.5,0,0) → (0,0,2.5)
```

### 3.5 `GH` — 螺旋 / 螺线（⚠ 两版同名不同义）

**NEC-2 语义**（生态默认）：

```
GH  ITG  NS  S  HL  A1  B1  A2  B2  RAD
```

| 字段 | 含义 |
|---|---|
| `S` | 螺距（相邻匝的轴向间距） |
| `HL` | 轴向长度（z 从 0 到 HL；**符号决定旋向**，>0 为绕 +z 右手） |
| `A1/B1` | 起点椭圆半径（x/y） |
| `A2/B2` | 终点椭圆半径 |
| `RAD` | 导线半径（**恒定**） |

采样（段**等角**内接）：`θ(t) = 2π·HL·t/S`；`x = (A1+(A2−A1)t)·cos θ`；`y = (B1+(B2−B1)t)·sin θ`；`z = HL·t`。

**NEC-4 语义**：

```
GH  ITG  NS  TURNS  ZLEN  HR1  HR2  WR1  WR2  ISPX
```

| 字段 | 含义 |
|---|---|
| `TURNS` | 匝数（可小数；**符号决定旋向**，>0 为绕 +z 右手） |
| `ZLEN` | 轴向长度（z 从 0 到 ZLEN） |
| `HR1/HR2` | 起点/终点**螺旋半径**（`HR2=0` ⇒ 取 HR1） |
| `WR1/WR2` | 起点/终点**导线半径**（沿杆**对数**缩放；`WR2=0` ⇒ 取 WR1） |
| `ISPX` | `0`＝对数螺线 `r = r₁·a^θ`；`1`＝阿基米德螺线 `r = r₁ + a·θ` |

**同一行、两种读法**（真实数据）：

```nec
GH 1 15 1.54 -0.77 0.15 0.15 0.15 0.15 0.0025
```

| 读法 | 结果 | 判断 |
|---|---|---|
| NEC-2 | 螺距 1.54 m、轴向长 −0.77 m（半匝左旋）、半径 0.15 m、线半径 2.5 mm | **合理** |
| NEC-4 | 匝数 1.54、ZLEN −0.77、HR=0.15、`WR1=WR2=0.15 m`（＝150 mm 线半径）、`ISPX=0.0025`（非法标志） | **荒谬** |

**判定建议**：
1. **默认 NEC-2**（4NEC2/nec2c 及绝大多数文件都是 NEC-2 语义；审计中全部含 GH 的文件均为 NEC-2）；
2. 文件中出现 **NEC-4 专有卡**（`CW`/`SC`/`IS`/`JN`/`UM`/`VC`/`LE`/`LH`/`PS`/`MX`/`CP`/`GF`/`WG`）时倾向 NEC-4；
3. 启发式：F5/F6 明显小于 F3/F4（线半径 ≪ 螺旋半径）⇒ NEC-4；F5–F8 成对相等且 F9 很小 ⇒ NEC-2；
4. **最稳妥**：提供选项或在导入时询问用户。

### 3.6 `GM` — 坐标变换与复制

```
NEC-2:  GM  ITGI  NRPT  ROX  ROY  ROZ  XS  YS  ZS  ITS
NEC-4:  GM  ITGI  NRPT  ROX  ROY  ROZ  XS  YS  ZS  IT1  IS1  IT2  IS2
```

- `ROX/ROY/ROZ`：绕 x/y/z 轴的旋转角（度，**右手为正**）；顺序**固定**：Rx → Ry → Rz → 平移 `(XS,YS,ZS)`，一律相对固定坐标系。
- `NRPT=0` ⇒ **移动**（原位置不留结构）；`NRPT>0` ⇒ 原结构保留、生成 `NRPT` 份，**每份由前一份再变换一次**。
- `ITGI`：每复制一份各段 tag 递增一次（`tag=0` 不递增）⇒ 第 j 份 tag = 原作 + j·ITGI。
- `ITS`（NEC-2）：**起始段 tag**，范围"从该 tag 的第一个段到结构末尾"；`0`/空 ⇒ 全结构。
  - ⚠ 按**十进制**读（`040` = 40，不是八进制 32）。
  - ⚠ 找不到该 tag 时 NEC 报错终止；解析器宜"从宽按全结构 + 告警"。
- `IT1/IS1/IT2/IS2`（NEC-4）：可同时限定**结束段**；`IS1/IS2`＝该 tag 组内第 m 段（`IT=0` 时表示绝对段号）。

```nec
GW 1 1 0 0 0 1 0 0 0.01
GM 0 2 0 0 0 0 1 0        ' 复制 2 份，每份再向 +y 平移 1 m ⇒ y = 1、2
GM 0 0 0 0 90 0 0 0 0     ' 整个结构绕 z 转 90°（不复制）
GM 0 0 0 0 0 0 0 5 3      ' 从 tag=3 的段起，向 +z 平移 5 m
```

### 3.7 `GX` — 坐标面镜像（**最易读错**）

```
GX  ITGI  IXYZ
```

- `IXYZ` 是**一个三位整数**（NEC-2 手册：卡片第 8/9/10 列；NEC-4 手册：三个独立数字）：

| 数字 | 位 | 镜像面 | 效果 |
|---|---|---|---|
| 百位 | 1xx | **y-z 面**（沿 x 轴镜像） | `x → −x` |
| 十位 | x1x | **x-z 面**（沿 y 轴镜像） | `y → −y` |
| 个位 | xx1 | **x-y 面**（沿 z 轴镜像） | `z → −z` |

- 份数：`100`/`010`/`001` ⇒ 2 份；`110`/`101`/`011` ⇒ 4 份；`111` ⇒ 8 份。
- **执行顺序＝逆字母序：先 Z、再 Y、后 X**（每一面把"当前全部段"一起镜像）；**tag 增量每次翻倍**。
  手册例：`IXYZ=011`、`ITGI=100` ⇒ 先 Z 得 tag 101–200，再 Y 得 tag 201–400（增量翻倍为 200）。
- ⚠ **常见错误**：把 `IXYZ` 当三个独立字段（`GX 40 010` 读成 `IXX=10` ⇒ 镜像到 X 面、份数也错）。
- 手册示例（菱形天线，1 根变 4 根）：

```nec
GW 1 10 -350. 0. 150. 0. 150. 150. 0.1
GX 1 110
GS 0 0 0.3048
GE
```

### 3.8 `GR` — 圆柱阵列

```
GR  ITGI  NR
```

- 把**当前结构**绕 z 轴旋转复制成 `NR` 份（**含原作**），相邻两份夹角 `360/NR`，tag 每份递增 `ITGI`。
- 等价关系：`GR ITGI NR` ≡ `GM ITGI NR−1 … ROZ = 360/NR`（差别是 `GR` 会置"圆柱对称"标志以加速求解）。
- ⚠ 结构不得有段落在 z 轴上或跨过 z 轴（会产生重合段）。
- 实际文件中 `ITGI=0` 很常见（各份 tag 相同）；其后的十进制字段被忽略。

```nec
GW 10 80 0 0 0.1 40 0 0.1 0.0005
GM 0 0 0 0 45 0 0 0 10      ' 先整体转 45°
GX 12 110                    ' 再镜像出 4 条辐射地网
```

### 3.9 `GS` — 缩放

```
GS  0  0  FSCALE
```

前两个整数**不使用**（填 0）。`FSCALE` 乘到**所有结构尺寸上，包括导线半径**；按读入顺序生效（§2.3）。

### 3.10 `SP` / `SM` / `SC` — 面片（Surface Patch）

面片是**面**（不是线），用于金属板、柱面等；导线与面片连接时导线端点必须落在面片上。

```
SP  0  NS  X1 Y1 Z1  X2 Y2 Z2  [SC 0 0 X3 Y3 Z3  X4 Y4 Z4]     ' 单个面片
SM  NX NY  X1 Y1 Z1  X2 Y2 Z2  [SC 0 0 X3 Y3 Z3]               ' 矩形区域铺 NX×NY 个面片
```

- `SP` 的 `NS`：`0`＝只给中心点 + 法向仰角/方位角 + 面积（无形状面片）；`1`＝矩形；`2`＝三角；`3`＝四边形。
- 角点顺序决定外法向（右手法则）。
- **版本差异**：NEC-2 的 `SM` 自带三个角点（`X1..Z3`）；NEC-4 的 `SM` 只给角点 1、2，角点 3 由随后的 `SC` 给出（`SC` 为 NEC-4 新增）。
- ⚠ 面片不是线结构：只处理导线的工具应明确报"不支持"，不要静默忽略。

### 3.11 `GE` — 几何段结束

```
GE  I1  [I2]
```

- `I1`：地面镜像标志。`0`＝无地面；`1`＝有地面且落在 x-y 平面上的端点电流插值到镜像（底面电荷为零）；`−1`＝有地面但电流不修改（端点电流趋零）。
  ⚠ `I1` **不引入地面**，只让几何数据按"有地面"调整；地面参数由控制段 `GN`/`GD` 给出。
- `I2`（NEC-4）：段相交/细线近似检查开关（`0` 默认、`1` 报错即停、`2` 只报告不停）。
- `GE` 之后不得再出现几何卡。只关心物理导线的工具可忽略 `I1`。

### 3.12 `GF` / `WG` — 数值格林函数（NGF）

`WG` 把当前结构写成 NGF 文件；`GF` 读入 NGF 文件（必须是几何段第一张卡，`CM`/`CE` 除外）。真实文件中极罕见。

## 4. 控制卡

控制卡只影响**电磁解**；几何/结构类工具通常可忽略，但**必须能识别**（否则会误报"未知卡"）。

### 4.1 `FR` — 频率

```
FR  IFRQ  NFRQ  I3  I4  FMHZ  DELFRQ
```

`IFRQ`：`0` 线性步进 / `1` 倍乘步进；`NFRQ`＝步数（空＝1）；`I3`/`I4` 未用；`FMHZ`＝频率 MHz；`DELFRQ`＝步长/倍率。
单频最常见：`FR 0 1 0 0 14.1`。无 `FR` 时默认 299.8 MHz。

### 4.2 `EX` — 激励

```
EX  I1  I2  I3  I4  F1  F2  [F3 F4]
```

- `I1` 类型：`0` 电压源（外加场）、`1` 平面波（线极化）、`2`/`3` 平面波（椭圆极化 右/左旋）、`4` 元电流源、`5` 电压源（电流斜率不连续）；
  4NEC2/NEC-4 另有 `6`＝电流源。
- `I2`＝tag（`0` ⇒ `I3` 为绝对段号）；`I3`＝该 tag 组内第 m 段（或绝对段号）；`I4`＝源编号。
- 常见：`EX 0 1 11 0 1.0 0`（tag=1 的第 11 段，1 V）。

### 4.3 `LD` — 负载

```
LD  LDTYP  LDTAG  I3  I4  F1  F2  F3  [F4]
```

`LDTYP`：`−1` 清除全部负载；`0`/`1` 串/并联 RLC（Ω/H/F）；`2`/`3` 串/并联 RLC（每米）；`4` 阻抗（R、X，Ω）；`5` 导线电导率（S/m）。
常见：`LD 5 0 0 0 5.8e7 0`（铜）。NEC-2 的绝缘套用 `LD 7`，NEC-4 改用 `IS` 卡。

### 4.4 `TL` / `NT` — 传输线与网络

`TL I1..I4 F1..F6`：两端各用（tag, 段号）定位；`F1`＝特性阻抗（**负号＝交叉线/180° 反相**）、`F2`＝线长（空＝两点直线距离）、`F3..F6`＝两端并联导纳实虚部。
`NT I1..I4 F1..F8`：两端各用（tag, 段号）定位；`F1..F8` 为 Y 参数实虚部。

### 4.5 `GN` / `GD` — 地面

```
GN  IPERF  I2  I3  I4  F1  F2  F3  F4  [F5 F6]  [文件名]
```

`IPERF`：`−1` 清除地面；`0` 无地面；`1` 理想地面；`2` 有限电导地面（`F1`＝相对介电常数、`F2`＝电导率 S/m）；NEC-4.2 另有第三类地面模型。
常见：`GN 2 0 0 0 13 5.e-3`（εr=13、σ=0.005 S/m）。`GD`＝第二介质/悬崖参数，必须在 `GN` 之后。地面**不改变导线几何**。

### 4.6 NEC-4 新增的介质/电路类卡

| 卡 | 用途 |
|---|---|
| `IS` | 绝缘套（在段区间上给导线加绝缘层；NEC-2 用 `LD 7`） |
| `UM` | 上层介质（如冰层/水面上方的半空间参数） |
| `VC` | 电压源端帽（模拟有限半径开口端） |
| `JN` | 结点电荷处理方式 |
| `CP` | 两段间最大耦合计算 |
| `MX` | 矩阵内存分配 |
| `PS` | 打印各段电长度 |
| `LE` / `LH` | 沿指定直线的近电场/近磁场积分 |

### 4.7 输出与终止

| 卡 | 用途 |
|---|---|
| `RP` | 远场方向图请求 |
| `NE` / `NH` | 近电场 / 近磁场点阵 |
| `PT` / `PQ` | 电流 / 电荷打印选项 |
| `XQ` | 只算电流、不请求输出 |
| `EK` / `KH` | 扩展细线核等；**NEC-4 明说"包含但无效果"** |
| `NX` | 下一个数据集（§2.5） |
| `EN` | 文件结束 |

### 4.8 `CM` / `CE` — 注释

`CM` 行是注释文本（常用作模型标题，可多条）；`CE` 结束注释块。两者也可出现在文件其它位置（NEC-4 明确允许）。

## 5. `SY` 符号与表达式（4NEC2 生态扩展）

> ⚠ **前提**：`SY`（符号/变量）**不是 NEC-2 或 NEC-4.2 的官方卡**（两版手册均无），由 4NEC2、nec2c 等实现引入；
> 但在业余无线电模型中**使用极广**。解析"官方语法"不必支持；解析"实际文件"必须支持。

### 5.1 `SY` 卡语法

```nec
SY len=20                        ' 单个声明
SY len=20, hgh=10, width=0.1     ' 一卡多声明（逗号分隔；括号内逗号不算）
SY d=0.02*len  ! 注释             ' 值可为表达式；注释截断
```

- 名字规则：`[A-Za-z_][A-Za-z0-9_]*`；**大小写不敏感**。
- 变量可用在**任何后续卡的任何数值字段**里。

### 5.2 运算符与函数

| 类别 | 支持 |
|---|---|
| 运算符 | `+` `-` `*` `/` `^`（**`^` 是幂运算**） |
| 三角函数 | `SIN` `COS` `TAN` —— **角度制** |
| 反三角 | `ATN` —— **返回角度** |
| 幂/根 | `^`、`SQR(x)`（＝平方根，BASIC 风格）、`SQRT(x)` |
| 其它 | `ABS` `EXP` `LOG`（自然对数）`LOG10` `INT`（下取整）`FIX`（截断）`SGN` `MOD(a,b)` |
| 常量 | `PI` |
| 布尔/比较 | `and` `or` `not` `xor` `eqv` `<` `>` `<=` `>=` —— 手册列出，但真实文件中**未见使用** |

### 5.3 单位、常量与线规

- **长度单位字**（预定义标识符）：`cm` `mm` `in` `ft`；可作**数值后缀**（`27.5ft`、`1.2mm`、`135 ft`）或**裸用**（`SY Inp=mm` ⇒ 0.001；`56ft/in` ⇒ 56×0.3048/0.0254）。
- **电学单位字**：`pF` `nF` `uF` `nH` `uH`（如 `37.8uH`、`470pF`）；部分实现另接受 `mH`。
- **AWG 线规**：`#12`＝AWG 12 的**半径**（米）；`#12/ft`＝同一半径但**以 ft 计**（用于英尺制模型）；`#0000` 等 0 号线规亦可。
  半径＝直径 ÷ 2；直径可用标准式 `d(mm) = 0.127 × 92^((36−n)/39)`（n ≥ 0），或直接查表（附录 B）。

### 5.4 求值规则（**关键**）

1. **声明先于使用**：`SY` 必须出现在引用它的卡之前。
2. **按文件顺序求值**：同名重定义＝**顺序赋值** —— `SY DE=…, DE=DE*8` 的第二条用第一条的值（不是自引用）。
3. **位置相关**：同名变量在文件不同位置可表示不同值（真实文件用它做"循环"：每张 `GW` 前改一次 `ang`，画出不同方向的导线）。
4. **不支持前向引用**：引用尚未声明的变量 ⇒ 求值失败。
5. **求值失败**：不同实现不一致（4NEC2 报错；宽松实现常"吞 0"）——**吞 0 会导致几何静默塌缩**，务必告警。

### 5.5 表达式陷阱清单

| 写法 | 陷阱 | 正确处理 |
|---|---|---|
| `3^2` | 若用 JavaScript 风格求值，`^` 是**异或**（得 1 而非 9） | 把 `^` 当幂（先转 `**` 或自定义解析） |
| `-2^2` | 幂优先于一元负号 ⇒ 应为 −4 | 注意优先级；`-x**2` 在 JS 中语法非法，需改写为 `-(x**2)` |
| `+00.27685`、`05.33467` | 前导零小数在部分语言中**非法** | 数值规范化：按十进制读 |
| `0021` | 会被当**八进制**（=17） | 同上，按十进制 |
| `0.5D1` | 可能是"0.5 × 变量 D1"（隐式乘法），也可能是 Fortran `D` 指数（=5） | 需明确口径；未见手册支持隐式乘法 |
| `A + H`、`H+ L/2 + 0.05` | 表达式**内含空格** ⇒ 按空白切字段会错位 | 按字段个数/表达式语法还原字段 |
| `-68 ft` | 数值与单位字间有空格 ⇒ 单位成独立字段 | 数值后紧跟的单位字并入同一字段 |
| `1/2UH` | 单位属于**字面量**：= 1/(2 µH) | 单位后缀与数字绑定 |
| `R01LENGTH` | 名字里的数字不是隐式乘法 | 用词法分析，不要用正则猜 |
| `#12/ft` | `#` 线规与 `/` 单位组合 | 支持 `#NN[/unit]` |
| `10IN` 与 `INT(` | 单位后缀与函数名可能混淆 | 单位后缀要求前面是数字且后面不是字母/数字 |

## 6. 版本差异总表

| 卡 | NEC-2 | NEC-4.2 | 兼容性提示 |
|---|---|---|---|
| `GW` | `ITG NS X1..Z2 RAD` | 同 | 一致（`NS=0`/`RAD=0` 语义两版相同） |
| `GC` | `GC <空> <空> RDEL RAD1 RAD2` | `GC IX 0 RDEL RAD1 RAD2 [DEL1 DEL2]` | 自由格式字段位置一致；`IX=1/2` 仅 NEC-4 |
| `CW` | **无** | `CW ITG NS X1..Z2 RAD ICAT RHM ZM` | 仅 NEC-4 |
| `GA` | `ITG NS RADA ANG1 ANG2 RAD` | 同 | 一致 |
| `GH` | `ITG NS S HL A1 B1 A2 B2 RAD` | `ITG NS TURNS ZLEN HR1 HR2 WR1 WR2 ISPX` | **同名不同义**（§3.5） |
| `GM` | `… XS YS ZS ITS` | `… XS YS ZS IT1 IS1 IT2 IS2` | 无范围限定时一致 |
| `GX` | `ITGI IXYZ`（三位数字） | 同 | 一致（都要按"一个整数"读） |
| `GR` | `ITGI NR` | 同 | 一致 |
| `GS` | `GS 0 0 FSCALE` | 同 | 一致（含半径） |
| `GE` | `GE I1` | `GE I1 I2` | 一致（`I2` 仅 NEC-4） |
| `SP` | `SP 0 NS …` | 同 | 一致（`NS=0/1/2/3`） |
| `SM` | `NX NY X1..Z3`（自带 3 角点） | `NX NY X1..Z2` + 随后 `SC` | **字段数不同** |
| `SC` | **无** | 续行卡 | 仅 NEC-4 |
| `IS`/`UM`/`VC`/`JN`/`CP`/`MX`/`PS`/`LE`/`LH` | 无 | 有 | 电学/输出类 |
| `EX` | 类型 0–5 | 另有电流源类型 | 4NEC2 用 `EX 6` |
| `GN` | `IPERF` 0/1/2 | 另加第三类地面模型（4.2） | 只影响电磁解 |
| `EK`/`KH` | 有效 | **无效果** | 可忽略 |
| `SY` | 非官方（生态扩展） | 非官方 | §5 |

**同名不同义的三个卡**：`GH`（参数全不同）、`GM`（NEC-4 多出范围字段）、`GC`（NEC-4 多出 `IX`/`DEL1`/`DEL2` 语义）。
处理原则：**默认按 NEC-2**；检测到 NEC-4 专有卡或用户指定时按 NEC-4。

## 7. 真实文件容错表

| 现象 | 出现面 | 建议处理 |
|---|---|---|
| 尾注释 `'` / `!` / 弯引号 | 很常见 | 字段切分**前**截断 |
| 表达式内含空格（`A + H`） | 少 | 按字段个数还原字段；否则整体错位（**严重**） |
| 数值与单位字间有空格（`-68 ft`） | 少 | 并入前一个纯数值字段 |
| 前导零小数（`+00.27685`）、`0021` | 少 | 按十进制规范化 |
| `#NN` / `#NN/ft` 线规 | 少 | 支持；未知线规告警（勿静默 0） |
| `NS` 为小数表达式 | 常见 | 四舍五入/截断（与目标引擎一致） |
| `NS=0` 的 `GW` | 少 | 不生成线段（常用来"关掉"可选导线） |
| `RAD=0` + `GC` | 少 | 展开锥度；无 `GC` 时告警并丢弃该导线 |
| `GM` 的 `ITS` 前导零（`040`） | 少 | 按十进制（＝40） |
| 多数据集（`NX`） | 极罕见 | 只取第一个 + 告警（**不要合并**） |
| 面片 `SP`/`SM`/`SC` | 少 | 明确"不支持"告警 |
| 未知双字母卡 | 偶见 | 告警；同时把 NEC-4 新卡列入已知清单 |
| 空行/缩进/制表符/全角空格 | 常见 | 跳过或当分隔符 |
| 行首 `*` 注释 | 未见 | 可选容忍 |

## 8. 实现清单与算法要点

### 8.1 清单

**必备（缺了必错）**

1. 按字段序号读卡（列位置仅历史约定）；分隔符＝空格/逗号/制表符。
2. `GW`：`NS=0` 不生成段；`RAD=0` ⇒ 读下一张 `GC`。
3. `GC`：段长规则 `IX=0/1/2` + 半径几何级数（§3.2）。
4. `GX`：`IXYZ` 为**一个整数**，位映射 X/Y/Z，顺序 Z→Y→X，tag 增量翻倍。
5. `GM`：变换顺序 Rx→Ry→Rz→平移；`NRPT=0` 是移动；tag 每份 +ITGI；`ITS` 十进制、范围到末尾。
6. `GR`：旋转复制 `NR` 份（含原作），角度 `360/NR`。
7. `GS`：缩放**含半径**，且只作用于"已读入"结构。
8. `GE`：几何段结束标志。
9. `SY`（若要吃真实文件）：**按文件顺序求值**、声明先于使用、同名顺序赋值、`^` 是幂、单位字、AWG `#NN`。
10. 注释截断（`'`、`!`、弯引号）在字段切分之前。

**建议（避免静默错）**

11. `GH`：默认 NEC-2，提供 NEC-4 选项/询问。
12. `CW`：`ICAT 1/2/3` + 等弧长内接。
13. `NX`：只取第一个数据集并告警。
14. 未定义符号/求值失败 ⇒ **告警**，不要静默 0。
15. 未知双字母卡 ⇒ 告警（而不是当注释忽略）。
16. 零长度导线、`RAD ≤ 0`、重复端点 ⇒ 告警并跳过。
17. 生成/复制类卡要有**数量护栏**（段数上限、复制总量上限），防异常参数导致内存爆炸。

**可选（提升忠实度）**

18. 表达式内空格、隐式乘法（需先定语义）。
19. `SP`/`SM`/`SC` 面片。
20. 段级操作（`EX`/`LD`/`TL`/`NT` 的 tag+段号定位）——只在需要电磁侧语义时实现。

### 8.2 推荐数据结构

```
Wire { tag: int, ns: int, p1: (x,y,z), p2: (x,y,z), rad: float }   # 米制
SymbolTable = map<string, number>                                   # 名字大写
```

导线列表按读入顺序保存；`GM`/`GX`/`GR` 的复制以"列表快照 + 逐份追加"实现；`GS` 直接就地缩放列表内全部坐标与半径。

### 8.3 关键算法要点

- **`GX` 位提取**：`X = ⌊IXYZ/100⌋ mod 10`、`Y = ⌊IXYZ/10⌋ mod 10`、`Z = IXYZ mod 10`（非零即镜像）；按 Z→Y→X 依次复制，`inc *= 2` 每次翻倍。
- **`GM` 旋转矩阵**：`R = Rz(ROZ)·Ry(ROY)·Rx(ROX)`，再平移；右手系。
- **`GM` 复制**：第 j 份 = 对第 j−1 份再变换一次（不是对原作变换 j 次），tag 每份 +ITGI。
- **`GC` 段长**：按 §3.2 公式生成长度序列后**归一化到总长 L**（消除数值误差）。
- **`CW` 悬链线**：曲线在两端点决定的竖直平面内，水平坐标 u∈[0,D]、高度
  `z(u) = z₁ + a·[cosh((u−u₀)/a) − cosh(u₀/a)]`，其中 `u₀ = D/2 − a·asinh(Δz/(2a·sinh(D/(2a))))`，`Δz = z₂−z₁`。
  弧长 `s(u) = a·[sinh((u−u₀)/a) + sinh(u₀/a)]`。由 `ICAT` 给出约束后**反解 a**（`a` 越大越接近直线；建议在对数域扫描找区间再二分），
  再按等弧长采样：`u(s) = u₀ + a·asinh(s/a − sinh(u₀/a))`，`s = k·L_total/NS`。
  退化（两端水平距离≈0，或 `ICAT=3` 且给定长度 < 直线距离）⇒ 生成一根直杆。
- **`GH`（NEC-2）**：`θ(t) = 2π·HL·t/S`，半径线性插值；段等角内接。
- **`GH`（NEC-4）**：`θ(t) = 2π·TURNS·t`；半径按 `ISPX` 的对数/阿基米德律由 `HR1→HR2` 决定；导线半径按 `WR1→WR2` **对数**缩放（逐段一个半径）。
- **`SY` 求值器**：可用"符号表文本替换 + 表达式求值"，但必须：按文件顺序、`^`→幂、单位字与 AWG 先处理、失败返回"错误"而非 0（由调用方决定是否告警跳过）。
- **护栏建议**：单卡生成段数上限（如 5000）、复制总量上限（如 200000 段），超限时告警并截断/跳过。

```nec
CM 5-element Yagi, 20 m band
CE

SY el=0.5*wl, sp=0.2*wl
SY rad=#14/ft                     ' AWG 14 半径（以英尺计）

GS 0 0 0.3048
GE 0
EX 0 2 11 0 1.0 0
FR 0 1 0 0 freq
EN
```
