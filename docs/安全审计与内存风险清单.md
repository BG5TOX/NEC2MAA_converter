## 2. 风险列表（v04 复核 + R21 增量）

### S1 · evalExpr 的 new Function 求值面 — LOW（已验证受控，接受项）【未修·维持接受】
- **位置**：utils.js L38 `new Function('return (' + s + ')')()`
- **v04 复核**：不变。NEC 输入全链 `cleanLine.toUpperCase()` 大写化构成事实沙箱（alert/fetch/constructor 链实测不可达）。**接受现状**；重构 evalExpr 前必须保留大写化链或改显式白名单解析器。

### S2 · evalExpr 符号键正则元字符 → 未捕获异常（DoS 自身工具） — MED【**已修复 2026-09-03 (SF1)**】
- **位置**： utils.js L20 `new RegExp("\\b" + key.toUpperCase() + "\\b", "g")`
- **修复**： 键构造正则前 `replace(/[.*+?^${}()|[\]\\]/g, '\\$&')` 字面量化。修复后 `A(`/`A*`/`A?`/`[A]` 键实测不抛异常；正常键替换与长键优先不受影响；元字符键与 `\b` 词边界不构成匹配位时静默不替换（安全语义）。验证 sf1 7 断言。

### S3 · CM 卡换行注入面（writer 单行净化缺失） — MED 契约【**已修复 2026-09-03 (SF2)**】
- **修复**： writer 头部 `oneLine()` 统一净化（`[\x00-\x1F]+` 折叠为空格）应用于 maaTitle/cmOverride/fileName。实测 override 含 `\nGW 1 999 …` → 折叠为同一 CM 卡内的空格文本，无伪造独立卡行；文件名 `\n` 同净化。验证 sf2 4 断言。

### M1 · GM NRPT 资源放大（浏览器 OOM/挂起） — MED【**已修复 2026-09-03 (SF1)**】
- **位置**： geometry.js GM 复制循环
- **修复**： 导线总量预算 200,000——`projected = wires.length × (nrpt+1)` 超预算即停止扩展并告警（"[警告] GM 复制次数 N × 现有 M 根导线将超总量预算 200000, 已停止扩展 — 模型不完整, 请人工核查源文件的 NRPT 值。"）。实测 `GM 0,1e8` 1ms 拦截不 OOM；预算内 5×40000=200000 正常；小复制/原地旋转路径不变。验证 sf1 5 断言。

### M2 · createObjectURL 从不 revoke — LOW【**已修复 2026-09-03 (SF1)**】
- **位置**： app.js downloadMaa
- **修复**： `const url = …; a.click(); removeChild(a); URL.revokeObjectURL(url)`——下载引用已被浏览器捕获，立即 revoke 安全。验证 sf1 2 断言。

### M3 · readFileSmart 纯 ASCII 快速路径 `String.fromCharCode.apply` 栈溢出 — **NEW**·MED（R21g 引入）【**已修复 2026-09-03 (SF1)**】
- **位置**： app.js readFileSmart 纯 ASCII 分支
- **修复**： 改 `new TextDecoder('utf-8').decode(buf)`（ASCII 是 UTF-8 子集，恒无损、恒无 U+FFFD，无参数列表上限）。实测 1MB ASCII 直解正常（原实现 200KB 即栈溢出）。验证 sf1 3 断言。

### R1 · NaN/Infinity 向下游传播无门禁 — LOW【**已修复 2026-09-03 (SF2)**】
- **修复**： writer 输出前 R1 门禁——频率非有限正数/导线坐标半径（含锥度子段）非有限 → `[错误]` 告警 + 抛异常拦截（不产出非法 NEC）；半径零/下溢（JS parseFloat 下溢为 0）→ `[提示]` 告警不拦截。实测：z=NaN 拦截、`1E999` 频率拦截、`1E-999` 半径下溢告警产出、锥度 def R=NaN 在 parser 对级校验拒收（更前置）、正常文件零感知。验证 sf2 7 断言。

### R2 · CM 标题卡无长度上限 — LOW【**已修复 2026-09-03 (SF2)**】
- **修复**： 原标题卡同注释截断策略——超 70 字符截为 69+`~`。实测 5000 字符标题 → `CM <69字符>~`（73 字符含前缀）；恰 70 不截断；短标题原样。验证 sf2 3 断言。

### S4 · `$$$` 计数行悬空无告警（parser 防御缺口） — **NEW**·LOW【**已修复 2026-09-03 (SF2)**】
- **修复**： parser 三处检查（节头切换/注释节切换/EOF）——`$$$` 区声明数与实际解析数不符 → `[警告] $$$ 锥度区声明 N 个组合, 实际仅解析到 M 个 (文件结束/遇节头中断/遇注释节中断)`。实测 EOF 悬空（5/0）、节头中断（3/1，已解析定义保留）、jp2000 全量（10/10）无告警。验证 sf2 4 断言。

### I1 · 无 CSP meta — INFO【维持备查】
- file:// 本地工具无外联无 XSS 面；Web 宿主时需补 CSP。
