v0.6 = v0.5 + **NEC 几何/卡片解析审计修复**。UI/i18n/锥度重建/安全修复零改动——本版仅修 N2M 几何卡解析（GM/GX/GW），并因版本标记升 v0.6 重审定 M2N 723 文件 hash 基线。

## 2. 修复清单

| 卡片 | 缺陷 | 修复 |
|---|---|---|
| **GM** | 第 10 字段 **ITS (F7)** 被完全忽略（一律作用于全部导线）→ 多组结构互相污染；NRPT>0 副本为「每副本 = 原作 + 同一变换」（非累积） | ITS 限定「第一个 tag==ITS 的线段到结构末尾」（按线段位置，0/空=全结构；未命中→`n2m.gm.itsNotFound` 告警 + 全结构从宽）；副本逐轮累积 `C_j=T^j(原作)`（NEC-2 `move()`），tag 每轮只加一次 ITG；预算 `n + nrpt·(n−start)`；平移随 GS 缩放 |
| **GX** | I2 被当成独立 X/Y/Z 三字段；实为**三位数字标志**（百/十/个 = X/Y/Z）→ `010`/`011`/`111` 全部误判为 X | 按原始文本从右取位（规避 `evalExpr` 前导 0 八进制陷阱 `"010"→8`）；反射序 Z→Y→X，tag 增量 1/2/4 倍 ITG；tag=0 不递增 |
| **GW** | 半径空白/0 = `GC` 锥度续行卡；旧实现空白静默丢弃、0 产出非法零半径 | 跳过并按文件聚合单条 `n2m.gw.gcTaper` 告警 `{tag,count}` |

实测样例 `samples/2M_70CM_STACK_2MBAND_extra_ref(1).NEC`：旧 548 根 → 新 **164 根**（70cm 128 短 + 2m 36 长）。
全库 1126 个真实 `.nec` N2M 解析冒烟：0 异常，42,544 根导线。
