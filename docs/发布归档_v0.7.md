# NEC2MAA_converter v0.7 发布归档（2026-09-24）

## 1. 版本定位

v0.7 = v0.6 + **NEC 解析审计修复**（`docs/NEC解析功能审计报告.md` 2493 文件全量审计落地，方案见 `docs/NEC解析修复落地方案.md`）。
UI/i18n/锥度重建/安全修复零改动——本版集中在 **N2M 解析链路**（表达式层 / SY / GS / 卡片层 / 告警架构），并因版本标记升 v0.7 重审定 M2N 723 文件 hash 基线。

用户裁决（2026-09-24，10 项）：全 P0–P2 范围；GS 失败**阻断**；SY **顺序求值**；GS **NEC-2 顺序语义**（段范围不应用+告警）；求值失败**跳过导线+聚合告警**；`^` **括号感知 Math.pow**；GR **本轮实现**；升 **v0.7**；隐式乘法**符号感知**；app.js **try/catch + 告警统一**。
