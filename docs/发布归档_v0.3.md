## 3. 功能清单（v0.3 全量）

**N2M（4NEC2 .nec → MMANA-GAL .maa）**——继承 v02 全部：
- GW/GX/GM 仿射变换（NRPT 复制语义）、SY 符号表求值、GS 单位后缀、
  GN 映射（S-N 降级+告警）、LD 手册七类型、EX 全类型（0/5/6 映射、1-4 丢弃+告警）、
  偏移设计符（±1 保留/>1 收敛+告警）、Load 四重校验、几何卡/扫频告警
- v0.3 增：**天线材料下拉**（0-6，选项不显数字）+ **附加高度**输入（G/H 行字段 2/3 按新语义）

**M2N（MMANA-GAL .maa → 4NEC2 .nec）**——v0.3 新增：
- 双变体解析（A/B，单星/三星/俄文节头兼容，形态分类防 CP1251 变码）——**722 官方库 100% 解析**
- SY 参数化输出（f/h/D1..Dn 无上限一卡一参/负载 L·C·Q 或 R·X，半径 `0.5*Dn`，z `+h`）
- **G/H 新语义**：字段 2 附加高度→`SY h=`、字段 3 材料→M>0 提示自设、字段 7 jX
- 馈电百分比锚定（c→50%、b→1、e→100%、偏移收敛+告警）
- **强制分段**开关：默认段 1+醒目警告（NEC 自动分段接管）；勾选→`ceil(len·ρ/λ)` 按 Segs/λ（默认 25，典型 15~100，无效拦截）
- 地面参数全手动（自定义/27 项 Ground.txt 预设，σ/εr 未填全拦截；自由空间禁用+清空）
- 纯 ASCII 强制输出（终检断言）+ 非英文注释聚合警告丢弃 + CM 头英文摘要
- 722 文件转换冒烟 + ASCII 0 违例（T1'）

**UI**：向导开屏→双工作区→右上返回；方向嗅探（节头特征/扩展名）；标题双模式（含扩展名）；下载 `.nec`/`.maa` 按方向。

## 7. 已知边界（不修复清单）

- S 参数负载（12 字段×8 文件）不映射（告警+注释）
- 并联负载网络/元电流源/EX 平面波丢弃（告警）
- LD Variant-A 六字段原值直出（单位语义未证，告警人工核查）
- M2N 手动正数段（26 例）忽略；`$$$ Taper wire set $$$` 扩展区跳过
- N2M 不含 σ/εr 输入（.maa 无此数据，G/H 行只存类型/高度/材料）
- GM 多轴旋转序（Rz·Ry·Rx，有告警）、连续 GM 重复 tag 首匹配
- evalExpr 注入面（本地工具可接受）
