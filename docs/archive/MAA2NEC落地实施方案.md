## 2. 输出格式规范（修订 2）

### 2.1 卡序模板（现行版）

```
CM Converted from <文件名> by NEC2MAA v0.3. <原标题(纯英文时)>
CM Original: seg mode=-1 (auto), dm1=800 dm2=80 sc=2.0 ec=2. Wires: <n>.
CM Note: all segments set to 1. Enable 4NEC2 auto segmentation before run.
CM Dropped non-ASCII comments: <k> line(s) from <###Comment###/title>.
CE
SY f=<频率>
SY h=0
SY D1=<最大直径>
SY D2=<次大直径>
…（每个参数独立 SY 卡；直径降序，种类不设上限）
SY L1=10.8            ← 仅负载存在时，逐参数独立
SY C1=0
SY Q1=200
GW 1, 1, x1, y1, z1+h, x2, y2, z2+h, 0.5*D1
GW 2, 1, …, 0.5*D1
…（段数列恒 1；半径字段 0.5*Dn）
GE 1
EX 0, 1, 50%, re, im, 0, 0, 0      ← 百分比锚定(§2.3)；re/im 由 phase/mag 数值化
LD 1, 1, 50%, 50%, 2*PI*f*L1*1E-6/Q1, L1*1E-6, C1*1E-12
GN <按 G/H 行映射>
FR 0, 1, 0, 0, f, 0
EN
```

**与修订 1 模板的差异**：
- 注释区从"EN 后 `!` 逐行"改为**头部 CM 卡**（英文摘要）；NEC 语法中 CM 连续多行天然合法（每行独立 CM 卡）
- 提醒信息进 CM 头（`Note: … Enable 4NEC2 auto segmentation`），不再用尾部 `!` 卡
- 原 `###Comment###` 长注释：**纯英文的**以英文摘要并入 CM（超长时截断至合理行宽 + `…`）；**含非英文的整行丢弃 + 聚合警告**
- EX/LD 的 re/im 与数值字段照旧；卡序不变（CM→SY→GW→GE→EX→LD→GN→FR→EN——符合 NEC-2 顺序：SY 在几何前、GN 在 FR 前）

### 2.2 SY 参数化细则（修订 2）

- **一卡一参**：`SY D1=0.002`、`SY D2=0.001`…（4NEC2 SY 语义即单卡单符号，逗号多参反而非标准写法）
- **直径降序无上限**：扫描全部线半径去重 → 降序 D1≥D2≥…≥Dn 全符号化；GW 半径字段 `0.5*Dn`（`/2` 写法全文件废除，统一 `*0.5`）
- **h**：`SY h=0`；z 字段 `<原z>+h`
- **负载**：LC 型逐参 `SY L1=`/`SY C1=`/`SY Q1=`；LD 1 的 R 字段 `2*PI*f*L1*1E-6/Q1`（Q≤0 → 写 `0`）；R+jX 型 `SY R1=`/`SY X1=` → `LD 3, tag, 50%, 50%, R1, X1`
- **f**：全局共享
- **符号名规范**（ASCII 强制下自动满足）：`f/h/Dn/Ln/Cn/Qn/Rn/Xn` 全为 ASCII 字母数字

### 2.3 馈电点定位（修订 2 无变化，现行表）

| .maa 设计符 | 输出 EX 段号 | 说明 |
|---|---|---|
| `w?c` 纯中心锚 | `50%` | 与段数解耦 |
| `w?b` 纯起点锚 | 段号 `1`（**非 `1%`**，永不漂移） | |
| `w?e` 纯末端锚 | `100%`（T5 实测；不识别则 `99%` + 告警） | |
| `w?±n` 带偏移 | 收敛最近纯锚 + `[警告]`（含原设计符与去向） | seg=1 下偏移不可恢复 |
| Variant A 源行 | seg>0 → `(seg/n*100)`%；seg≤0 → 三锚规则 | 仅老收藏库 |

备选 SY segs 方案（V2 开关）存档不变——若启用，其中 `(segs+1)/2` 按修订 2 规则写作 `0.5*(segs+1)`。

### 2.4 ASCII 强制与注释策略（修订 2 新增专节）

**强制规则**：输出文件（含标题、CM 摘要、全部卡面字段）**只允许 ASCII 可打印字符**。实施三处把关：
1. **标题行**：原 .maa 标题纯英文 → 保留进首行 CM；含非英文 → 丢弃 + 计入聚合警告（官方库 48 文件触发）
2. **`###Comment###` 注释**（240 文件有此节，59 含非英文）：
   - 纯英文行 → 英文简要表达并入 CM 头（"简要"定义：保留关键信息原文，行宽超 ~70 字符截断加 `…`；不翻译不改写，只做必要修剪）
   - **含非英文行 → 整行丢弃**，弹**聚合警告**（见下），不尝试转码/转译
3. **聚合警告格式**（每文件最多一次，不逐行骚扰）：
   ```
   ⚠️ 源文件含 12 行非英文注释/标题，已按"纯 ASCII 输出"策略丢弃（占原注释 8/20 行 + 标题）。
      丢弃内容仍保存在 .maa 原文件中；如需保留请自行转译后手填。
      原文件: <文件名>
   ```
   同步计数进 CM 头（`CM Dropped non-ASCII comments: 12 line(s).`）——**NEC 文件自身始终无任何非英文**，警告只出现在浏览器 alert，不进输出。

**数据佐证**：官方库 722 文件中整文件纯 ASCII 仅 335 个（54% 文件将触发至少一项丢弃警告）——聚合警告设计避免了对超半数用户的弹窗轰炸；英文注释的保留/摘要规则对纯 ASCII 的 383 文件零打扰。

## 3. 模块设计（修订 2）

```
js/maa2nec/
├── maa-parser.js     # 双变体检测 + 分节收集: {title, freq, wires, sources, loads, segParams, ground, comments[]}
│                     #   + 注释 ASCII 检测: 每行标记 isAscii; 非 ASCII 行计数聚合
│                     #   疑点核实: SEG 小数形态(λ 模式?) R1 首个任务
├── maa-symbols.js    # SY 推导: 半径去重降序→D1..Dn(无上限); 负载 L/C/Q 或 R/X 逐参编号; h/f
│                     #   输出一卡一参的 SY 卡序列
├── maa-writer.js     # 卡序组装: CM 头(英文摘要+丢弃计数) / SY 逐卡 / GW(段1, 0.5*Dn, z+h)
│                     #   / EX(百分比) / LD(表达式) / GN / FR / EN
│                     #   + 输出前 ASCII 终检: 全文正则 [^\x20-\x7E\n] 扫描, 违例即内部断言(测试用)
└── (设计符解析并入 maa-parser)
```

- ASCII 终检正则 `[^\x20-\x7E\n\r\t]`：writer 输出前跑一遍，正常流程应恒零违例（防御性断言）；T1 冒烟对 722 文件逐个验证"输出纯 ASCII"
- UI/告警通道同修订 1（方向切换、`m2nWarnings` 独立、聚合警告 alert）
