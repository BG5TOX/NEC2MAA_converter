# M2N 锥度振子重建 — 落地实施方案（R21）

> 2026-09-03 起草。状态：**待用户确认后实施**。
> 范围：仅 M2N（MAA→NEC）方向；N2M 不动。功能默认开启，不加控制选项（用户决策）。

## 0. 需求复述

.maa 中负数半径的导线 = 引用预定义锥度组合；锥度组合定义在 `$$$...$$$` 区。M2N 须把每根锥度导线**重建为多根首尾相连、半径不同的子导线**输出到 NEC（GW 卡序列），否则几何模型错误。示例文件 `F:\Antenna\jp2000_147.maa`。

## 1. 事实勘察结论（官方库实证）

### 1.1 `$$$` 区形态（20 个文件全量扫描）

- **双语言标签**：英文 `$$$ Taper wire set $$$`（9 文件）与俄文 `$$$ Установки комб. пров. $$$`（CP1251 读出为变码串，11 文件）。**解析只认 `$$$` 前缀，不匹配标签文字**（R1 已定案：西里尔变码不可靠）。
- 区内第一行 = **组合数量**（同 `***Wires***` 计数行语义），随后每行一个组合定义。
- 组合定义行：`名称(负半径值), Type, L1, R1, L2, R2, …, L10, R10`（最多 10 对）。jp2000 一行 10 字段（4 对）；Short 160m 文件 16 字段（7 对）。

### 1.2 单位定案：文件数值 = 米（半径），与线行 rad 列一致

用户描述 "R1(mm)" 为 **MMANA 编辑器 UI 语义**；**文件存盘值为米**。证据：

| 证据 | 内容 |
|---|---|
| 4EL20HM 标题 | `"4ele 20m Hairpin-Match (30mm/25mm/20mm Pipe)"` ↔ 定义 R=0.015/0.0125/0.01（m 半径 → 30/25/20mm 直径，×2000 严丝合缝） |
| 物理常识 | 8EL6MW（6m 波段）R=0.007 → 14mm 直径（合理）；若按 mm 读 = 14µm（荒谬） |
| 列一致性 | 锥度半径与线行 rad 同为"替换半径"语义，dx415tt 普通线 rad=0.0025m 与锥度 R=0.013 同量纲 |

L 同理为米（下文长度算术全部闭合验证）。

### 1.3 Type 字段定案：文件存 0–3 = UI 编号 1–4 减一

用户给的是 UI 编号（1=中心向两端、2=起点向末端、3=中心向两端、4=起点向末端，几何上 1≡3、2≡4）。**文件实际存 0/1/2/3**（库中四种全见到）。映射与几何证据：

| 文件 Type | 几何证据 | 结论 |
|---|---|---|
| **0 / 2 = 中心向两端（对称）** | 4EL20HM 寄生单元 type=2 [1.8,1.8,尾] 挂 10.81m 全长单元：1.8×2+1.8×2+尾 1.805×2 = 10.81 ✓，且标题"30mm/25mm/20mm Pipe"=中心粗末端细的经典对称锥度 | jp2000 全部 type=2 挂全长对称单元 ✓；dx415tt type=0 同 ✓ |
| **1 / 3 = 起点向末端（顺序）** | 4EL20HM 馈电半单元 type=1 [0.85,1.8,尾] 挂 4.96m 半振子：起点即馈电端，粗段在馈电处（hairpin 机械结构合理）；dx415tt type=3 同为 DE 半单元 | — |

即：**对称型 = file 0/2；顺序型 = file 1/3**。均匀/非均匀分段差异（file 0/1 vs 2/3）只影响原程序分段策略，M2N 只关心几何 → 忽略。
⚠️ 此为"UI 编号−1"解释 + 几何实证的合并结论，**与用户描述在偏移解释下完全自洽**；若用户按文件原值理解（1=中心），则映射需翻转——实现中收敛为**单点常量表**（一行可改），请在确认批复中明示。

### 1.4 哨兵与裁断

- 尾对 L=99999.9 = "末梢"：从上一段累计位置延伸到线段端点，长度 = 线长 − 前面各段和。判定阈值：`L ≥ 99999` 视为哨兵（容忍变体）。
- 库中 20/20 文件的定义都带哨兵尾对；但累计和可超线长（4EL20HM DE 半单元 0.85+1.8 < 4.96 有尾；jp2000 w3 2.0+0.9=2.9 > 半长 2.76 → **尾对不存在，第 2 对被截断**——两类都真实存在）。

## 2. 数据模型

```js
// maa-parser.js 新增（result 扩展）:
parsed.taperDefs = { byName: Map<负半径数值, {type, pairs: [{L, R, isTail}] , lineNo}>,
                     count, definedCount }

// maa-taper.js（新文件）输出:
rebuilt = {
  wires: [ {x1,y1,z1,x2,y2,z2, rad,           // 子导线（或未锥度原导线原对象）
            segRaw, origIdx,                   // 溯源：原线号（1-based）
            arcStart, arcEnd} ],              // 在原线弧长坐标 [0, origLen]
  origToSubs: [ per原线: [{gwIdx0, arcStart, arcEnd}] ],
  expanded: bool, expandedFrom: N, expandedTo: M
}
```

## 3. 重建算法（maa-taper.js，纯函数）

输入 `parsed.wires` + `taperDefs` + `warnings`；导线为直线段（.maa 线行即直线），子段端点按弧长比例对 (x1,y1,z1)→(x2,y2,z2) 线性插值。

1. **非负半径** → 原样保留（同一对象引用，保证 702 普通文件字节不变）。
2. **负半径查表**：`taperDefs.byName.get(rad)`；未命中 → 告警 `[错误] 锥度名 {rad} 未在 $$$ 定义区找到, 该线已按 1mm 半径直出, 请人工核查` + 以 rad=0.001 原样输出（不弃线，拓扑保全）。
3. **顺序型（file 1/3）**：自线起点累进：段 k 覆盖 `[cum_{k-1}, min(cum_k, L)]`；哨兵对覆盖 `[cum_last, L]`；累计和 < L 且无哨兵 → 余长沿用最后一对 R + 告警。
4. **对称型（file 0/2）**：中心 c=L/2。逐对向两侧等长展开（左 `[c-cum_k, c-cum_{k-1}]`，右镜像）；尾对 = 距中心剩余；某对累计 ≥ 半长 → 该对截断于半长、后续对与尾对全部不存在。输出按**空间顺序**（起点→终点）排列：左半（对序倒排）+ 右半（对序正排）。
5. **零长子段**（截断余量 ≤1e-9，如假想 w9 尾若再短）：跳过 + 告警（NEC 拒零长线）。
6. 子段 `rad` 取该对 R（米），`segRaw` 继承原线第 8 字段。

## 4. 写入器集成（maa-writer.js）

- `writeMaaToNec` 头部：`const rebuilt = expandTaperedWires(parsed.wires, parsed.taperDefs, parsed.warnings)`；`buildMaaSymbols` 改吃 `rebuilt.wires`（半径符号集自动含全部子段半径；L/C/Q、h/f 符号不变；SY 一卡一参/`0.5*Dn`/无上限约定不变）。
- GW 循环改遍 `rebuilt.wires`：tag 连续 1..M；`z+h`、坐标 swap、强制分段密度（每子段独立按 len·ρ/λ）全部照旧。
- **锚点重映射（EX/LD）**：原设计符 → 原线弧长位置（b→0、c→L/2、e→L；±1 脉冲偏移沿用现行"收敛纯锚+告警"）→ 定位子段：
  - 单子段线（未锥度）→ **完全走现行 anchorToSegField 路径，输出逐字节不变**（'50%'/'1'/'100%'）。
  - 落在子段边界（对称型 c=左右半交界、b、e）→ 取**后继子段段号 1**（整数段号，T5 已覆盖 '1' 语义；规避待定的 '100%'）。
  - 落在子段内部（顺序型 c 可能落于首段之中）→ 局部百分比 `round((p-arcStart)/(arcEnd-arcStart)*1000)/10 %`（如 43.2%）——**新增 T5 待测矩阵项**。
- CM 头：仅当 `rebuilt.expanded` 时插入一行 `CM Tapered wires: N original(s) expanded to M connected GW sections (per $$$ taper table).`（位于 Original 行之后）；同时 warnings 弹一次汇总 `[提示] 检测到 N 根锥度振子(负半径), 已按 $$$ 锥度组合重建为 M 根相连线段。`
- ASCII 终检照旧（重建不引入非 ASCII）。

## 5. 解析器改动（maa-parser.js）

现 `$$$` 处理为跳过（L142）——改为**捕获**：进入 taper 模式，吃计数行，随后逐行解析定义（名称<0、type∈Z、L/R 对至字段尾），至计数满足或遇下一节头。防御：计数缺省 0；定义行字段非法跳过+告警；重名取首个+告警；type 超界（>3/NaN）按 0 处理+告警。节头/`###`/线区判别逻辑不动（$$$ 区固定在 G/H 后出现于全部 20 个库文件，但实现不依赖位置）。
