## 3. extractFromNec 拆分明细（265 行 → 1 编排 + 4 解析器）

原函数结构（保持行为不变的拆法）：
```
extractFromNec(text, showPrompts)
  ├─ 逐卡首遍循环: parseHeaderCards(line) → 更新 symbols/freq/ground/groundWarning/frSweepNote/geomCardWarnings/hasTL/hasLD/unknownCards
  ├─ collectWires(...)                          ← geometry.js
  ├─ 第二遍 EX 循环 → parseExcitation(line, wires, symbols, parsedSources, exNotes, fuzzyPositionWarnings)
  ├─ hasLD 时第三遍 LD 循环 → parseLoads(...)
  └─ 告警编排(顺序不可变): groundWarning → geomCards → frSweep → unknownCards → TL → failedLD → ld1Notes → ld5Notes → exNotes(块外!) → fuzzyPosition
```
拆分规则：**解析函数只做单卡解析与状态追加；编排函数持全部局部变量并控制告警顺序**。注意 exNotes 告警块必须在 `if (hasLD)` 块外（v02 修复 1 的缺陷形态，回归用例 §10 有专测）。

## 4. executeConvert 拆分明细（140 行 → 1 编排 + 5 构建器）

```
executeConvert()
  ├─ 读输入(freq 空校验) + SY/GS 预处理循环(保持) + collectWires
  ├─ validateLoadRows(loadLines) → {good, bad, badNotes}      ← 3.7 四重校验
  ├─ buildWiresSection(wires, axisMap) → maaLines 片段
  ├─ buildSourceSection(sourceLines)                           ← p.length>=3 重排逻辑保持
  ├─ buildLoadSection(goodLoadLines)                           ← 数量行 ,0
  ├─ buildTailSections()                                       ← Segmentation/G-H(第3字段固定0)/###Comment###
  └─ 组装 + gsUnitNote/gmNotes/unsupportedErrors 写入顺序保持
```
