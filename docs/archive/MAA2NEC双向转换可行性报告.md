## 1. 结论先行（v2 重估）

**可行，评级升至 ★★★★★（方案完全确定）**。初版三大理由之上，用户决策带来关键简化：

1. **OpenNEC 参考实现完备**（不变）——823 行 `read_deck_maa` 定义了双变体/设计符/GN epsr 推导的全部语义边界
2. **信息单调性**（不变）——MAA→NEC 是低密度→高密度方向，无信息损失
3. **【新】auto-seg 难点整体消失**——初版评估的唯一硬骨头（SEG=-1 → 具体段数重建）因"分段统一 1 + 4NEC2 自动分段接管"策略**砍掉**：98.9% 官方库文件本就 SEG=-1（auto 模式），统一输出段数 1 后由 4NEC2 的 Auto Segment 恢复等效语义，且 OpenNEC 导入器的 `(segs+1)/2` 百分比思想证明 4nec2 生态本就接受"段数后置"的建模
4. **【新】官方测试基准 722 文件**——`C:\MMANA-GALBasic3\ANT`（12 分类目录）可直接做全量解析冒烟 + 结构断言 + 往返测试，无需自建用例

**工作量重估**：约 1.5–2 个 v02 批次（原估 2–3 个），R1–R4 四批（详见落地实施方案 §5）。

## 4. 馈电点定位方案（v2 核心细化，用户问"更好的方法"）

**选定方案：百分比锚定**（用户决策，与 seg=1 策略构成"位置-段数解耦"——4NEC2 自动分段下两者互不干扰，位置永不漂移）：

| .maa 设计符 | EX 段号字段 | 理由 |
|---|---|---|
| `w?c` 纯中心锚 | `50%` | 任意段数解析为中点段；OpenNEC 导入器的 `(segs+1)/2` 同思想 |
| `w?b` 纯起点锚 | **段号 `1`（非 `1%`）** | `1%` 会漂（50 段线→段 0.5 钳 1，200 段线→段 2）；**段号 1 与总段数无关，永不漂** |
| `w?e` 纯末端锚 | `100%`（T5 实测 4NEC2；不识别则 `99%` 兜底 + 告警） | 末段语义 |
| `w?±n` 带偏移 | 收敛最近纯锚 + `[警告]`（含原设计符） | seg=1 下偏移脉冲位置不可恢复；v02 修复 3 已证自动分段下偏移本就近似——不做不可靠换算 |

**备选方案存档（V2 开关，首版不做）——SY segs 参数化段数**：`SY segs=<N>` + GW 段数列写 `segs` + EX 写 `(segs+1)/2`（OpenNEC 导入器 maa-support.c:534-560 同款表达式）。适用"用户想手动控制分段密度"的场景；与首版"统一段 1 + 自动分段"策略互斥，故留作输出模式开关。4nec2 原生支持 SY 符号求值（v02 的 evalExpr 即其语法子集），技术无障碍。

**为什么百分比优于具体段号**（结论依据）：seg=1 输出下任何具体段号（如"段 15"）在 4NEC2 自动分段重算后必然错位；百分比是 4NEC2 官方语法（其解析器按当前段数求值），是唯一与"段数后置"策略自洽的定位方式。代价：其他 NEC 软件（xnecview 等）对段号字段百分比的兼容性不保证——**本工具目标生态明确为 4NEC2，此代价已由用户确认接受**（输出提醒卡中注明）。
