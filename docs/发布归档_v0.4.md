## 3. 锥度语义最终规范（v0.4 核心）

- `$$$` 区（英文 `Taper wire set` / 俄文变码标签）：首行=组合数；每行= `负半径名, Type, L1, R1, …, L10, R10`
- **单位=米**（存盘统一；"R(mm)" 为 MMANA 编辑器 UI 语义）
- **Type（文件存 0–3 = UI 编号−1）**：0/2=中心向两端（对称）、1/3=起点向末端（顺序）；均匀/非均匀分段差异忽略（只关心几何）
- **对称型长度**：L1=中心节整体长度；L2~L10=每侧长度；L≥99999 尾哨兵到端点；L1/2 超半长时中心节截到整根
- **中心节不拆分**（R21c）：跨中心单段输出，馈电锚 `w?c` 落其内部 50%
- 负半径引用；未定义名→1mm fallback+告警；锚点重映射（b/c/e→弧长→子段；边界→段号 1，内部→局部百分比）
- 判别文件断言固化：jp2000（10→56）、8EL6MW（3 段）、4EL20HM（三管 30/25/20mm）、dx415tt（7 段）

## 5. 已知边界

1. 台阶半径相连 GW 的电气影响（接点突变）为物理固有——CM 说明行+弹窗提示已含"请人工核查"
2. 锥度锚点子段内部百分比（43.2% 形态）与 "tag, 1" 复合段字段为 T5 待实测项
3. 变体 A（无节头）文件未在库内发现负半径线——A 变体锥度路径未实测（parser 不依赖节头位置，理论兼容）
4. TextDecoder('windows-1251') 在极老浏览器缺失时回退 UTF-8（显示乱码但转换仍正确）
5. R1 门禁拦截异常值（NaN/Infinity）时为 fail-fast——用户须修源文件（告警文案指明位置）
