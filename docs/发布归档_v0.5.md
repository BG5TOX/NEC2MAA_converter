## 3. 语言包架构（面向未来扩展）

- **机制/数据彻底分离**：i18n.js 无任何文案；术语/句子全部在语言包内独立编辑（UTF-8 文本编辑器直改，Ctrl+F5 强刷生效）
- **`{{terms.x}}` 术语引用**：句子内引用术语表条目，改一处术语全语言包引用句同步
- **新增语言三步**（机制零改动）：复制 `js/i18n/en.js` → 改 meta+翻译（缺键自动回退 en→zh，翻译一半可用）→ index.html 加一行 `<script>`；下拉/toggle/校验测试自动纳入
- **file:// 结构性约束**：语言包为可执行 JS 数据文件而非 JSON（浏览器 file:// 下禁 fetch 本地 JSON）；每包"单注释头+单赋值"，i18n_lang.js 做语法预检防编辑手误

## 4. B1 双视图契约（核心）

所有转换告警不再是中文字符串，而是结构化条目 `{key, params}`，两个出口分别渲染：
- **屏显**：`alert(L(key, params))` — 跟随界面语言（zh 模式下文案与 v0.4 逐字一致）
- **写入输出文件**：.maa 的 Warnings 区 / .nec 的 CM 摘要与 R1 拦截消息 — `LF(key, params)` 恒英文（.nec 受 ASCII 终检结构性约束；两方向行为对称）
